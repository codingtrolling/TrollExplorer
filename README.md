# TrollExplorer (Shizuku Edition)

A lightweight Android File Explorer built via terminal, featuring root-level browsing via **Shizuku**.

## Features
- **Root Browsing:** Access `/` using Shizuku Binder.
- **File Management:** Copy, Move, Rename, Delete.
- **Archives:** ZIP compression and extraction.
- **Metadata:** Real-time storage usage and file details.
- **Search:** Instant filtering of files and folders.

## Build Instructions
This project is configured to build via **GitHub Actions**. Simply push your code to a GitHub repository, and the APK will be generated automatically in the 'Actions' tab.
